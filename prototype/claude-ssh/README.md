# OpenCode на Mac, Claude Code на VPS

Прототип для Apple Silicon. На Mac OpenCode выполняет файловые операции и shell-команды в каталоге запуска. Его провайдер Claude Agent использует JavaScript-клиент Agent SDK и запускает официальный Linux-бинарник Claude Code по SSH. Claude Code обращается к Anthropic-совместимому API DeepSeek. Нативная зависимость Claude для Darwin исключена из локальной сборки. Проект, его зависимости и Git находятся на Mac. Содержимое запросов и результатов инструментов проходит через VPS к модели.

## Запуск на этом Mac

Из рабочего каталога запустите `opencode-vps`. По умолчанию выбран `claude-agent/deepseek-flash`. После закрытия открыть последнюю сессию можно через `opencode-vps --continue`, конкретную — через `opencode-vps --session <ID OpenCode>`. Для одного сообщения:

```sh
opencode-vps run 'Покажи текущую рабочую папку'
opencode-vps run --session <ID_OpenCode> 'Продолжай'
```

Лаунчер использует отдельные каталоги OpenCode под `~/.local/share/opencode-claude-vps`. Каждый запуск работает с приватным процессом сервера OpenCode (`--standalone`). Для обычной работы действуют разрешения OpenCode. Только автоматическая smoke-проверка запускается с `--auto` в новом тестовом каталоге.

## Граница между машинами

- Пользователь сервера — `oc-claude-proto`. Бинарник — `/var/lib/oc-claude-proto/bin/claude` (2.1.328). Только серверный процесс получает токен для `https://api.deepseek.com/anthropic` из файла режима `0600`. Между Mac и VPS используется отдельный SSH-ключ с forced command. TCP-сервис для моста открывать не требуется.
- `bridge.py` читает одну строку параметров запуска, затем передает stdin/stdout напрямую Claude Code. Путь локального проекта хешируется в имя отдельного служебного каталога. Среда Mac не пересылается на VPS. В `launches.jsonl` записываются только метаданные запуска. Нативные диалоги хранятся под `/var/lib/oc-claude-proto/state/projects`; локальная история OpenCode тоже сохраняется.
- `transcripts.mjs` выполняет операции поиска, удаления и ответвления серверной сессии через Agent SDK. Перезапуск и продолжение проверены живым тестом. Ответвление и удаление не входят в этот сквозной тест.
- Два хоста видны как разные среды. В исходном системном контексте Claude Code указывает Linux; добавленная инструкция явно задаёт рабочую папку и платформу локальных инструментов.
- Доверяйте серверу, ключу подключения и рабочему каталогу. Shell работает с правами запустившего OpenCode пользователя на Mac. Прототип не изолирует код от существующих пользовательских доступов Mac, включая другие SSH-ключи.

## Сборка и проверка

Исходный коммит OpenCode — `ca729da9a54078e8fe5c73707d94421405a7b834`. Запустите `python3 prototype/claude-ssh/build-mac.py` из чекаута с Bun 1.4.4 на PATH. На этом Mac закреплённая версия лежит в `~/.local/share/opencode-claude-vps/toolchain/bun`. Скрипт собирает локальный терминальный клиент без встроенного web-интерфейса и восстанавливает необходимые платформенные зависимости из версий в lockfile. Бинарник находится в `packages/cli/dist/cli-darwin-arm64/bin/opencode`.

Для повторения проверки укажите новый пустой путь. Это две платные операции модели плюс возможные служебные запросы OpenCode (например, для заголовка).

```sh
python3 prototype/claude-ssh/verify.py "$HOME/harness-temp/oc-verification-$(date +%s)"
```

Проверка создаёт уникальный маркер в локальном файле и независимую фразу в сообщении. После выхода первого OpenCode запускается другой процесс с тем же ID. Проверяются код завершения, ID, вызовы инструментов, вывод `uname -s` и `pwd`, ответ модели и содержимое файла после обеих правок.

19 ноября 2026 года проверка прошла. OpenCode ID — `ses_e0ab1165dffe9ryo6y3ub7mlz8`, нативный Claude ID на VPS — `9606943e-fdf4-438e-ae3d-64a6ee272893`. В одном серверном журнале присутствовали оба пользовательских сообщения по одному разу и ответы `deepseek-flash`. Рабочий файл на Mac прошёл состояния `pending → first → second`; на VPS файла с таким именем в рабочем дереве не было.

## Установленные компоненты

Клиент использует SSH-алиас `opencode-nl` из `~/.config/opencode-claude-vps/ssh_config`. Отдельный закрытый SSH-ключ остаётся в этой папке Mac. На VPS в каталоге `/var/lib/oc-claude-proto` находятся `bridge.py`, `transcripts.mjs`, `bin/bun` (1.4.4), CLI, JavaScript SDK (0.3.301), рабочие каталоги и нативные сессии. Вход для ключа моста ограничен строкой `restrict,command="/usr/bin/python3 /var/lib/oc-claude-proto/bridge.py"` в authorized_keys этого отдельного пользователя. Ротация ключа DeepSeek делается на VPS заменой `deepseek.key` с сохранением владельца и прав; новое значение подхватит следующий процесс.
